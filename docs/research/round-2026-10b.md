## Results

Notional 10,000 USDT, base costs 12 bps per fill. Files: [results/](results/).

| Identity | Window | Base PnL | Benchmark | Null p | Outcome |
|---|---|---|---|---|---|
| v56 `taker_persist_long` | dev 2020–22 | −640 | +2,032 | 0.697 | rejected (36 positions, loss) |
| v57 `deleveraging_rebound` | dev 2022–23 | +2,138 | +176 | 0.105 | rejected (p, 2023 negative) |
| v58 `xs_taker_rotation` | dev 2020–22 | +2,567 | +147 | 0.281 | rejected (p, years, months) |
| v59 `turn_of_month` | dev 2020–22 | +7,034 | +3,114 | 0.010 | passed |
| v59 `turn_of_month` | conf 2023–25 | +1,714 | +1,682 | 0.224 | rejected (p) |

- v59's development edge came mostly from 2021 (+6,771 of +7,034) and from
  days 1 and 3; in confirmation days 1 and 2 earned and day 3 lost. An
  unstable day pattern plus p 0.224 reads as noise.
- v57 missed on p by 0.005; under W3 it is not rescued. ETH metrics start
  2021-12-01, so ETH could not trigger before 2022-03.
- Persistence filtering (v56) removed F1's gross edge instead of keeping it.

## Cost study (exploratory, 2026-10-18)

Operator direction: test whether lower trading costs rescue the cost-hit
signals. Fees checked against Binance: spot 0.1%, 0.075% with BNB; USD-M
perps 0.02%/0.05% maker/taker, 10% off with BNB. Scenarios per fill: 12 bps
(current), 9.5 bps (spot + BNB), 6.5 bps + funding (perp taker). Run only on
already-opened development windows; no protocol, no confirmation opened.

| Identity | 12 bps net / p | 9.5 bps net / p | perp 6.5 bps + funding net / p |
|---|---|---|---|
| v55 taker_continuation | +3,417 / 0.115 | +4,582 / 0.115 | +6,402 / 0.106 |
| v57 deleveraging_rebound | +2,138 / 0.105 | +2,313 / 0.105 | +2,434 / 0.099 (fails years, months) |
| v58 xs_taker_rotation | +2,567 / 0.281 | +3,009 / 0.281 | +3,423 / 0.283 |
| v55 oi_squeeze, v56 | losses at every cost | | |

- Lower costs raise net PnL but barely move p: the timing null pays the same
  turnover at the same cost, so cost cannot create timing skill. Cost only
  matters for a signal with real timing edge and negative net; none qualified.
- Perp longs pay funding: mean 0.034–0.044% a day across the universe
  (2020–2025), about 12–16% a year, which outweighs the fee saving for
  multi-day longs. That same flow is what a funding-carry position collects.
- No new protocol was opened. `apps/research` now supports `um_funding`
  (perp returns net of funding) for any future perp or carry protocol.
